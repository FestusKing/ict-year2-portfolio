Der Editor konnte nicht geladen werden

Das CMS wird von unpkg.com nachgeladen. Wenn dein Netzwerk (z. B. das Schul-WLAN) diese Adresse blockiert, erscheint diese Meldung.

Was du tun kannst:

  • Seite neu laden (Strg + F5)
  • Anderes Netz probieren, z. B. Handy-Hotspot
  • Notfall-Weg: Eintrag direkt auf github.com im Web-Editor bearbeiten
